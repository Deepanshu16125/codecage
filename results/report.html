How it is enforced

  • CPU: wasmtime fuel metering, with a per-plugin budget.
  • Time: epoch interruption plus a watchdog that hard-stops plugins stuck in host calls about 250 ms after the timeout.
  • Memory: a resource limiter caps linear memory growth.
  • Output: stdout and stderr are captured in capped buffers.
  • Files and environment: capability-based WASI. A plugin sees only the folders its policy grants (read-only unless it says write) and only the named env vars.
  • Audit: every run is logged; codecage audit summarizes denials per plugin.
